# Support

Where a question goes depends on what kind of question it is.

| You have | Go to |
|---|---|
| A bug in a repository | That repository's issues, using the bug template. |
| A feature request | That repository's issues, using the feature template. |
| A question about how to use a product | That product's own support channel, linked from its README. |
| A security vulnerability | [SECURITY.md](./SECURITY.md). Never a public issue. |
| A conduct concern | `conduct@redrob.ai`. See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md). |
| A question about these standards | An issue or pull request on this repository. |

A useful bug report names the platform, the version, and what you saw on screen. A screenshot
of the actual window beats a description of it.

We do not provide support by direct message. A question answered in an issue is answered for
everyone who searches it later.
