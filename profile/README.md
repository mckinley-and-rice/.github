engineering standards every one of them follows are in
[`.github`](https://github.com/mckinley-and-rice/.github): branching, repository naming,
design tokens, and the rules an AI agent works under in our trees.

- Code of conduct: [CODE_OF_CONDUCT.md](https://github.com/mckinley-and-rice/.github/blob/main/CODE_OF_CONDUCT.md)
- Security reports: [SECURITY.md](https://github.com/mckinley-and-rice/.github/blob/main/SECURITY.md), privately and never as a public issue
